# Gioco delle Case • Maritano

PWA per la gestione del Gioco delle Case.

## File principali
- `index.html` — applicazione
- `manifest.webmanifest` — installazione PWA
- `service-worker.js` — cache/offline
- `icons/` — icone PWA
- `sounds/` — effetti sonori CC0 ottimizzati e crediti

## Pubblicazione
GitHub Pages da branch `main`, cartella `/ (root)`.

## Audio
La v3 usa Web Audio per il ding leggero dei comandi e file audio CC0 per gli eventi magici. I suoni sono inclusi nella cache offline.
